## 1.0.1

### Patch Changes

- Add support for Sanity Studio v6. Drop support for Sanity v3 and v4 — the `sanity` peer dependency is now `^5.0.0 || ^6.0.0`, and `react` is now `^19.2` (matching Sanity 5+).

## 1.0.0

### Major Changes

- Initial release: the `sectionBuilder` Studio plugin, `sectionField` /
  `sectionArrayMembers` helpers, schema-based section detection, and
  preview-asset auditing.
- Tooling: ESLint (`@sanity/eslint-config-studio`) + Prettier
  (`@sanity/prettier-config`) with a husky pre-commit hook running lint-staged,
  `knip` for unused-code detection, GitHub Actions CI (lint, format, type-check,
  knip, test, build), Dependabot, and Changesets-driven npm releases.

Releases after 1.0.1 are generated by semantic-release from commit messages:
edit those, not this file. 1.0.0 and 1.0.1 were written with Changesets.
